# 08 - Plan de Evolucion

## Roadmap tecnico

### Fase 1 - Robustez

- Suite de tests automatizados.
- Validadores avanzados de dataset.
- Pipeline de QA de datos.

### Fase 2 - Escalabilidad

- Heuristicas y poda inteligente.
- Paralelizacion de evaluacion de combinaciones.
- Persistencia opcional en base relacional.

### Fase 3 - Producto

- API REST para optimizacion.
- Multiusuario con historico de ejecuciones.
- Dashboard de analitica de recorridos.

## Criterios de exito

- Reducir tiempo de calculo por recorrido.
- Aumentar trazabilidad de decisiones del motor.
- Mejorar calidad y frescura de datos Google.
